# Планер

Легкий особистий планер: пишу задачу одним рядком, він сам розкладає її по даті й часу, нагадує, я відмічаю "зроблено". Веб-застосунок (PWA), який стоїть на головному екрані телефона.

## Ідея

Пишу: `зателефонувати лікарю завтра 10:00 #здоров'я`
Отримую: задачу на завтра о 10:00, тег "здоров'я", нагадування.

## Функції

**MVP**
- [x] Швидке додавання одним рядком (дата, час, теги розбираються з тексту)
- [x] Вигляди: Сьогодні / Завтра / Тиждень / Без дати
- [x] Відмітка "зроблено" (і повернення назад)
- [x] Редагування й видалення
- [x] PWA: іконка на головному екрані, працює як застосунок
- [x] Вхід через Supabase (щоб дані були однакові на телефоні й комп'ютері)

**Далі**
- [ ] Push-нагадування
- [ ] Повторювані задачі ("щопонеділка")
- [ ] Пріоритети, проєкти
- [ ] Темна тема
- [ ] Офлайн-режим

## Стек (пропозиція, можна міняти)

| Що | Чим |
|---|---|
| Фронтенд | Vite + React + TypeScript |
| Стилі | Tailwind CSS |
| База й вхід | Supabase (Postgres + Auth) |
| Розбір дат із тексту | chrono-node |
| PWA | vite-plugin-pwa |
| Хостинг | Vercel |
| Push-нагадування | Web Push + Supabase Edge Function з розкладом (cron) |

## Модель даних

Таблиця `tasks`:

| Поле | Тип | Опис |
|---|---|---|
| id | uuid | ключ |
| user_id | uuid | власник (Supabase Auth) |
| title | text | текст задачі |
| due_at | timestamptz, null | дата й час |
| has_time | boolean | чи вказано час (інакше задача на цілий день) |
| tags | text[] | теги |
| done | boolean | зроблено |
| done_at | timestamptz, null | коли зроблено |
| created_at | timestamptz | створено |

Row Level Security: кожен бачить лише свої рядки (`user_id = auth.uid()`).

## Швидке додавання: приклади

- `купити молоко сьогодні 18:00`
- `рахунки за світло 5 числа`
- `зустріч з Олегом в п'ятницю о 15` 
- `подзвонити мамі #сім'я`

Правило: усе, що схоже на дату/час, іде в `due_at`, слова з `#` у теги, решта в `title`. Якщо дати немає, задача потрапляє в "Без дати".

## Нагадування: що варто знати

- Android: Web Push працює одразу після встановлення PWA.
- iPhone: працює тільки після "Додати на головний екран" (iOS 16.4+).
- Нагадування приходять з сервера (cron в Supabase), тож працюють, навіть коли застосунок закритий.

## Запуск

```bash
git clone <посилання-на-репозиторій>
cd planner
npm install
cp .env.example .env     # вписати ключі Supabase
npm run dev
```

`.env`:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

Без цих ключів застосунок теж запускається: входу немає, задачі зберігаються лише в цьому браузері.

Тести розбору рядка: `npm test`.

## Деплой

1. Створити проєкт у Supabase, виконати SQL з `supabase/schema.sql`.
2. Запушити репозиторій на GitHub.
3. Vercel → Add New Project → вибрати репозиторій → додати змінні `VITE_SUPABASE_URL` і `VITE_SUPABASE_ANON_KEY` → Deploy.
4. Відкрити сайт на телефоні → "Додати на головний екран".
